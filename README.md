# 🚀 موقع حموكشة للدعاية وإعلانات المشروعات الصغيرة

الموقع الرسمي لحموكشة المتخصص في عمل الإعلانات والفلوجات ودعم وتكبير المشروعات الصغيرة والناشئة في محافظة سوهاج وجهينة ومراكزها الـ 13.

الموقع مبني باستخدام أحدث تقنيات الويب:
- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **TypeScript**
- **Lucide Icons**

---

## ❓ لماذا تظهر صفحة بيضاء عند فتح `index.html` مباشرة؟

عند تنزيل أي مشروع حديث مبني بـ **React & Vite** من GitHub، لا يمكن فتح ملف `index.html` بالضغط المزدوج كملف عادي (`file:///.../index.html`)، وذلك للأسباب التالية:
1. **سياسات الأمان في المتصفحات (CORS / Same-Origin Policy):** تمنع متصفحات الويب الحديثة (Chrome, Edge, Firefox, Safari) تشغيل وتحميل وحدات الجافاسكريبت الحديثة (`ES Modules`) عند فتح الملفات المباشرة من القرص الصلب (`file://`).
2. **ملفات TypeScript و JSX:** متصفح الويب لا يقرأ كود `main.tsx` مباشرة، بل يحتاج خادم Vite ليقوم بتحويله وترجمته تلقائياً لحظياً إلى جافاسكريبت يفهمه المتصفح.

---

## 🛠️ خطوات تشغيل المشروع محلياً على جهازك (في دقيقة واحدة)

### المتطلبات المسبقة:
- تثبيت **Node.js** (إذا لم يكن مثبتاً على جهازك، نزّله مجاناً من: [nodejs.org](https://nodejs.org)).

---

### الخطوة 1: فك الضغط وفتح موجه الأوامر (Terminal)
1. قم بفك ضغط ملف المشروع الذي نزلته من GitHub.
2. افتح مجلد المشروع.
3. افتح التيرمينال (Terminal على Mac/Linux أو Command Prompt / PowerShell على Windows) داخل هذا المجلد.

---

### الخطوة 2: تثبيت الحزم (Dependencies)
اكتب الأمر التالي واضغط Enter:
```bash
npm install
```
*(سيقوم هذا الأمر بتنزيل حزم React و Vite و Tailwind المطلوبة لتشغيل الموقع)*

---

### الخطوة 3: تشغيل خادم التطوير المحلي
اكتب الأمر التالي:
```bash
npm run dev
```

ستظهر لك رسالة تفيد بأن الموقع يعمل الآن:
```text
  VITE v8.3.7  ready in 200 ms

  ➜  Local:   http://localhost:3000/
```

---

### الخطوة 4: فتح الموقع في المتصفح
افتح متصفحك (Google Chrome أو أي متصفح) واذهب إلى الرابط:
👉 **[http://localhost:3000](http://localhost:3000)**

سيفتح معك الموقع بالكامل بجميع ألوانه، وتصميمه المتجاوب مع شاشات الهواتف والكمبيوتر، وصور حموكشة، والفلوجات والريلز، وأزرار الواتساب المباشرة!

---

## 📦 بناء نسخة نهائية للإنتاج (Production Build)

إذا أردت إنشاء نسخة مجمعة وجاهزة للرفع على أي استضافة ويب:
```bash
npm run build
```
سيتم إنشاء مجلد باسم `dist/` يحتوي على ملفات الموقع المجمعة والجاهزة للنشر على أي استضافة (مثل Netlify, Vercel, Firebase Hosting, cPanel).

لتجربة النسخة المجمعة محلياً:
```bash
npm run preview
```
